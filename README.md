# GameFinder
Contexto

Actualmente hay miles de videojuegos disponibles en diferentes plataformas, y todavía hay más por estrenarse. Muchos de estos cuentan con su género, estilo de juego, por lo que puede resultar difícil escoger uno y muchas personas terminan consultando recomendaciones en internet o simplemente escogen los juegos que se encuentran en tendencia en ese momento.

Por esta razón, mi proyecto consiste en desarrollar un algoritmo que recomiende videojuegos de acuerdo con las preferencias de cada usuario. El programa tomará en cuenta características como el género, la plataforma, dificultad y la duración del juego. A partir de las preferencias del jugador, el algoritmo comparará las opciones disponibles y se seleccionará un juego según una puntuación según qué tanto coincidan con lo que el usuario está buscando.

Considero que este proyecto es interesante, ya que muchas veces el comprar juegos no nos fijamos en muchas opciones y normalmente escogemos las que están en tendencia lo que por consecuencia nos limita de grandes posibilidades de lo que podría ser un juego popular. De igual forma este proyecto nos permite demostrar como un algoritmo puede utilizar la información proporcionada para tomar una decisión y ofrecer recomendaciones personalizadas.

Algoritmo

1.	Preguntar al usuario sus preferencias:

•	Género del videojuego

•	Plataforma

•	Nivel de dificultad

•	Duración aproximada

3.	Guardar respuestas del usuario
4.	Comparar las características que busca el usuario con los videojuegos disponibles
5.	Asignar puntuación a cada videojuego dependiendo de la cantidad de características que coincidan con las que asigno el usuario
6.	Comparar puntuaciones
7.	Seleccionar el videojuego con mayor puntuación
8.	Mostrar la recomendación obtenida
9.	Preguntar si se desea hacer otra consulta
10.	Si la respuesta es sí regresar al inicio. Si la respuesta es no, finalizar el programa.
